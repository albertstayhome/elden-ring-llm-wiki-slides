# 證據卡 [CARD-02]：翻滾無敵幀（i-Frames）與裝備負重
- **唯一綁定來源**：`[WIKI-02]` (`wiki/concepts/iframes-and-equip-load.md`) ← `[RAW-02 §2.1~§2.3]`
- **新手白話比喻**：翻滾不是為了逃離刀刃，而是開啟「0.216 秒的幽靈穿透防護罩」，迎著刀刃滾過去反而最安全。
- **允許引用之精確數據清單**：
  - 幀率基準：`60` FPS（每秒 `60` 幀）。
  - 輕負荷（`≤ 29.9%`）：`13` 幀無敵幀（`0.216` 秒）+ `8` 幀硬直 = 總計 `21` 幀；滾距比中負荷遠 `15%`。
  - 中負荷（`30.0% ~ 69.9%`）：`13` 幀無敵幀 + `8` 幀硬直 = 總計 `21` 幀（性價比最高黃金區間）。
  - 重負荷（`70.0% ~ 99.9%`）：無敵幀降至 `12` 幀，恢復硬直暴增至 `16` 幀（總計 `28` 幀，多出 `7` 幀破綻），耗精 `+20%`，回精每秒少 `9` 點（降低 `20%`）。
  - 超重（`≥ 100.0%`）：`0` 幀無敵幀，無法翻滾。
  - 獵犬步伐：`18` 幀無敵幀 + `4` 幀硬直，消耗 `5` 點 FP。
  - 無敵幀佔比：輕／中負荷翻滾總長 `21` 幀中，無敵期（`13` 幀）佔比高達 `61.9%`（約 `62%`），硬直期（`8` 幀）佔 `38.1%`（約 `38%`）。
